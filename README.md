# InsightFlo (인사이트플로)

AI software startup in Seoul, founded June 2025. Business registration no. 820-09-03326.

We build a **visual workflow automation platform** where AI agents execute and manage business workflows — composed visually, with execution tracking, retry/resume, and artifact verification (extended from the open-source [Paperclip](https://github.com/paperclip-ui/paperclip) base).

## Products

- **온보딩 (Manual Onboarding)** — AI-native daily news briefing. Research, drafting, publishing, and distribution run on a fully automated content pipeline. Live at [mock.co.kr](https://mock.co.kr)
- **GEO/SEO audit agent** — diagnoses search-engine and generative-AI visibility issues and auto-generates prioritized fix reports (in development)
